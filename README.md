This project was created for a Masters of Research (MRes) student where I assisted on the mechatronics part of the project. 
The project was bio-inspired in insect wings, with deformable trailing edge and adjustable AoT at 1/10th scale.
One potentiometer controls an MG996 servo applied for the trailing edge (higher torque requirement).
One potentiometer controls an SG90 servo for AoT.
ESP32 powered by 3.7V Lipo battery.
Coded in Arduino IDE.
Servos powered by external power supply.
